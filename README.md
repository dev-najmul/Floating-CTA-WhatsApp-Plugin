# Floating CTA & WhatsApp

A lightweight WordPress plugin that adds a **floating “Free Consultation” button** and a **WhatsApp chat icon** across your website.  
Perfect for lead generation, instant support, or contact prompts — all fully customizable from the admin panel.

---

## 🚀 Features

- **Floating position:** Choose left or right side, adjust bottom and side offsets.  
- **Two actions:**  
  - WhatsApp icon → opens a WhatsApp chat (`wa.me`) automatically.  
  - CTA button → links to any URL (appointment page, form, etc.).  
- **Fully customizable:**
  - Colors, shadows, border radius.
  - Button text, target URL, and WhatsApp number.
  - Gap between items and z-index.
- **Visibility control:** Show or hide on Desktop, Tablet, or Mobile.  
- **Toggle visibility:** Show both, only WhatsApp, or only the button.  
- **Responsive:** Looks great on all devices.
- **No external scripts or libraries.** One clean PHP file.

---

## 🧩 Installation

1. Download or clone this repository.  
2. upload the file in wp
3. Install it and activate it
